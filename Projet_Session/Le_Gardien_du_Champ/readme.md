# Le Gardien du Champ — Village V1

Projet Godot 4 basé sur le Labo02 Version 5.

## Nouveautés
- Nouveau fermier pixel art (sprite sheet 8 colonnes × 5 lignes), chapeau de paille et tenue rurale.
- Décor de village : maisons traditionnelles, arbres, collines, ciel et nuages.
- Sol en terre rouge avec herbe et cultures.
- Cinq plateformes en bois avec collisions physiques.
- Scripts de déplacement, FSM, tir et insectes conservés.

## Exécution
Ouvrir `src/project.godot` avec Godot 4.3 ou plus récent, puis F5.

## Contrôles
A / D ou flèches gauche/droite : déplacement. W / Espace / flèche haut : saut. J ou clic gauche : tir.

## Note
Cette version est une **transformation visuelle jouable**, pas encore le projet de session final. Les menus, les vies, les cultures destructibles, le score, les algorithmes, les sons et les scènes de fin restent à implémenter.
